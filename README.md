# Website Testing (Playwright)

Автоматизированные E2E-тесты для статьи **«Еноты»** на Википедии.

- **Тестируемый сайт:** [https://ru.wikipedia.org/wiki/Еноты](https://ru.wikipedia.org/wiki/Еноты)
- **Фреймворк:** Playwright
- **Язык:** TypeScript

## Что покрыто тестами

Согласно заданию, тесты покрывают 3 обязательных шага:

1. **Проверка текстов на странице** (`tests/01-text-presence.spec.ts`)  
   Проверяется наличие заголовков `Еноты`, `Название`, `Общие особенности`, а также ключевого текста в статье.
2. **Работа с формой и интерактивными элементами** (`tests/02-search-form.spec.ts`)  
   Тест открывает поле поиска, вводит запрос `Енот-полоскун` и проверяет, что осуществляется переход на страницу с соответствующим заголовком.
3. **Переход на другую страницу** (`tests/03-navigation.spec.ts`)  
   Тест кликает по ссылке `Енотовые` в тексте статьи и проверяет, что открылась новая страница с нужным заголовком.


## Установка и запуск

Установите зависимости:
npm install


Запустите тесты:
npm test

Откройте HTML-отчет с результатами:
npx playwright show-report --port 8080

После этого перейдите в браузере по адресу http://localhost:8080.
